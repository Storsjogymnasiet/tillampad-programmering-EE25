## Kursrepo

Alla elever i kursen ska starta ett eget repo som heter följande: TILL1000X-fornamn-efter. Det är där du kommer ladda upp all kod du skriver i kursen. Där följer du samma upplägg med att varje lektion har en egen folder som matchar lektionen du gör här i detta repo. Ex `01-linux`, `02-fjordjupning-linux` osv. Du kan se ett exempel i foldern `TILL1000X-fornamn-efternamn-exempelrepo`
